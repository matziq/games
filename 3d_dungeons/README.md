# Emberkeep: The Ashen Crown

Open `index.html` directly in a desktop browser. It is a self-contained, offline HTML5 action RPG with embedded artwork and no installation, external requests, or dependencies.

## Mobile and Android

Phone and tablet layouts use the available viewport height and safe-area insets, with no horizontal page scrolling. Drag the MOVE pad to walk and face the knight; hold Attack with another finger to keep striking. Tap the hall to aim without moving. Use / Equip opens chests, equips gear, trades, or descends; Dodge and Heal use the same resolve and potion rules as the keyboard. Touch cancellation and tab departure release held input. Gear / Map opens a compact equipment/map drawer and pauses the game; close it and tap Resume journey to continue. Music, sound effects, volume, pause, and new-run controls remain available. Desktop keyboard/mouse controls are unchanged.

The local Android package is `D:\OneDrive\Scripts\games\emberkeep\Emberkeep-Android.apk`; the standalone export is `D:\OneDrive\Scripts\games\emberkeep\Emberkeep.html`. Android 8.0 or later and an up-to-date Android System WebView are required. Copy the APK to the phone, open it from Files, allow that app to install unknown apps if prompted, and install Emberkeep. Start the adventure with Enter the halls to unlock audio. No Internet permission is requested: the complete HTML and embedded art are packaged inside the APK, and the WebView blocks external requests and navigation. Backgrounding pauses gameplay/audio and attempts a local save; Android Back asks before leaving.

This is a locally debug-key-signed, installable sideload build, not a Play Store release. Keep `android-debug.keystore` in the private output folder to sign compatible future updates; do not commit it or the APK. A production/Play Store release requires a separately managed release signing key and store submission.

An ongoing run saves locally about every two seconds of play and when the game is paused or the page is hidden. On reopening, choose **Resume saved run** or deliberately confirm **New run**. The save includes the current floor and its changes, inventory, equipment, enemies, traps, and progression. A completed death clears the run. Closing unexpectedly can lose up to the latest autosave interval. Saves belong to the current browser profile or Android app only; they do not sync across devices, between the website and APK, or between the website and standalone file. Clearing site/app data or uninstalling can remove the save. Storage errors and invalid saves are shown explicitly; an invalid save is not overwritten unless a new run is confirmed.

The tracked `android` directory contains a small native Java Activity, manifest, icon, and build script; it has no Gradle or third-party runtime dependencies. Install a JDK (21 used here), Android platform 36, and build-tools 36.0.0. Run `.\3d_dungeons\android\build.ps1` from the repository root, passing `-JavaHome` and `-SdkRoot` if needed. Defaults look for tools in the private output folder's `android-tools` directory. The script compiles Java with javac, converts it with D8, packages assets with AAPT2, aligns, signs, and verifies the APK; all build artifacts stay in the OneDrive output folder, not in the public Pages repository.

Run `python 3d_dungeons\mobile_checks.py` for phone portrait/landscape and tablet layout checks, simultaneous touch movement/attack, release, heal/dodge, gear, chests, stairs, merchant purchases, audio startup, and APK asset/DEX checks. Screenshots and JSON evidence go to `D:\OneDrive\Scripts\games\emberkeep`. An optional live `?test` URL repeats browser checks against deployment. Browser touch emulation does not substitute for native device testing.

## Play

WASD or arrow keys move. Mouse aims; hold left click on empty floor or Space to attack. Shift dodges in the movement direction (35 resolve; regenerates). Q drinks a potion (65 vitality). E opens nearby chests, equips dropped weapons or armor, collects pedestal treasure, and uses blue stairs. **T** cycles scrolls with a wand or shared ammunition with a ranged weapon; the cycle and heal keys can be customized. R casts the selected scroll. P or Escape pauses. New run confirms before replacing a live adventure.

Click or tap an item, chest, merchant, or stairway **within reach** to select it. Mouse clicks also aim and attack/fire, and holding the primary button keeps attacking even across selectable loot. Touch taps select and aim; the separate Attack button still strikes/fires while anything is highlighted. Selection never activates an item: **E / Use** remains deliberate. A gold dashed outline and named selection panel identify the target. Repeated clicks/taps cycle overlapping weapons and armor; the panel also lists separate buttons for each candidate. Clear, clicking empty ground, moving out of reach, or consuming the target clears selection; without selection, E retains its nearby-item behavior. Obstacles, furnishings, and torches are never selectable or usable. **Any melee or projectile weapon hit toggles a torch off or on, without fire**, including torches beneath selected loot. There is no F shortcut or separate touch Torch button; use Attack.

**X / Delete gear** removes only an explicitly selected loose weapon or armor, not equipped gear, treasure, or fixtures. The side selection panel's **Undo last delete** button restores that exact item once. Only the most recent deletion can be undone; another deletion replaces it. Undo does not change gold, equipment, monsters, or any other state. The latest deletion survives stairs, trapdoors, and fissures during the same run: on its original floor the item returns to its original location; after descent it returns safely at the knight's feet. A new run clears undo, and one-use restoration prevents duplication. All selection, Delete, Clear, and Undo buttons support touch.

Descend through **16 numbered floors** across five randomized realms, with two floors per realm and the final realm continuing through the cycle's later floors. Each realm has its own floor and wall palette, architectural motifs, torch color, ambience, and creature roster: flooded limestone halls, a thornwood castle, a moonlit crypt, a ruined keep, and the Cinder Forge. Stairs change the atmosphere and enemies when entering a new realm and restore vitality on every descent. **A boss guards every eighth floor**; the boss must fall before any route down opens. Cave spiders fire instant tracking webs that root you, then rush forward at high speed for an immediate melee strike; crypt wizards mark a location for lightning; cinder wizards launch fire that burns. Spell markers show where to dodge before impact. If you remain still for nine seconds, nearby floor markers warn that the dead are stirring; after twelve seconds zombies climb out beside you, extinguish every torch in your room, and attack. Moving resets the timer, but attacking does not. Gold and consumable drops collect on approach. Successful strikes show green damage values over enemies; actual health lost shows red values over the knight, accounting for armor and invulnerability. Nearby notifications stack, fade, and stay within the playfield. Equipment pickups compare their stats with your current gear before equipping; replaced equipment remains on the floor. Experience increases rank and vitality. The final boss on Floor 16 opens the next harder cycle; equipment, inventory, rank, gold, and crowns carry forward.

The knight stays upright in every direction: left-facing art is a horizontal mirror, not a rotated body. Weapons and attack arcs still aim independently in any direction.

## Shifting halls and room identities

Every floor includes eight distinct ordinary room identities, layered over its existing realm palette: a graveyard, provision stores, a winery, weapon armory, armor vault, silken nest, overgrown abandoned chambers, and ancient sanctuary. Their furnishings identify them visually. **Only Entrance Hall is labeled**, in the world and below the realm heading; other rooms and connecting passages have no room-name labels. Furnishings do not block movement or change the connected floor grid, but stop projectiles until broken. Only melee and projectile attacks destroy them, for exactly **1-2 coins**, once; no equipment or potion rewards come from decor. They never enter the item chooser or respond to E / Use. Breaking webbed eggs removes their associated slowing web patch. Torches, stairs, and merchants are not destructible.

Repeated bone glyphs, carpet stripes, colored floor-tile outlines, and other decorative tile marks have been removed for a cleaner stone floor. The supplied stone texture and masonry wall edges remain intact. Expired traps no longer show SPENT ovals. Active and SAFE traps, glints, inspection/countdown feedback, exit cues, and the actual earthquake cracks remain visible. Fissures retain their formation warning and gold-edged crack art without a repeated permanent floor label.

Earthquakes begin on **floor 3**. Floors 1-2 never quake. On non-boss floors, an occasional earthquake shakes the view and sounds a low rumble, then opens a gold-edged fissure after a three-second warning. The first can happen after 38-60 active seconds outside a merchant sanctuary; subsequent events are 45-70 active seconds apart, with at most three fissures per floor. Fissures have a brief opening grace period, remain visible on the floor, and drop you **exactly one floor** when walked or dodged across. They reuse the trapdoor descent path: input releases, vitality restores, and realm and merchant rules apply at the new entrance. Floors 8 and 16 never spawn pits or fissures; every other multi-floor descent is capped at the next boss floor, so no drop can skip a boss. Merchant sanctuaries suppress tremors; pausing and shopping do not advance these timers.

## Equipment

Crossbows fire fast bolts (720 units/second, 0.85-second recovery, longer reach and heavier base strike) and appear in normal equipment loot and merchant stock. All ranged weapons have unlimited regular shots. Chests always drop one random five-round special-ammunition pack; ordinary eligible loot sources have an 18% chance. All eight ranged weapons share one ammunition inventory and selection. **T**, or the cycle button on touch, selects regular ammunition or an available special type. Each successful ranged attack consumes one special round; cooldown and pause consume none. Switching to a wand or melee weapon drops every special round as floor packs preserving their exact counts; only ranged weapons can collect ammo.

Fire and Poison rounds add four seconds of burning/poison to the first creature hit. Explosion rounds burst for 35 additional damage within 75 units, respecting walls and damaging breakable obstacles. Lightning chains damage through nearby visible enemies; Web roots the first target; Charm temporarily turns a hit creature from the player. Light ammunition carries a soft, wall-bounded halo in flight and leaves one wider pool of light at its impact point (or maximum range) for five active gameplay seconds. These effects work on every ranged weapon, including thrown gear and firearms; pause does not age lingering effects. All shots stop at their first intact collider. Every melee and projectile weapon can **toggle** reachable torches, extinguishing lit sconces and relighting unlit ones without fire. A returning boomerang cannot toggle the same torch twice.

Longswords, war axes, flanged maces, spears, and halberds have distinct silhouettes both in your hand and on the ground. Longswords recover in 0.36 seconds; axes deal more damage with slower recovery (0.46 seconds); maces trade reach for impact (0.42 seconds); spears offer longer reach (0.40 seconds); halberds have the longest melee reach and heavier strikes (0.57 seconds). Longbows fire fast arrows (0.65 seconds), throwing spears launch heavier javelins (0.72 seconds), throwing knives recover rapidly with lighter damage (0.30 seconds), throwing axes spin with heavier impact (0.66 seconds), boomerangs return toward the knight (0.80 seconds; one in flight at a time), and black-powder rifles and pistols are ranged weapons offering long and quick firearm shots. Ranged weapons consume selected special ammo first, then use unlimited regular shots.

Player and enemy projectiles stop at the first living creature or container, including closed chests and container remains. A shot that breaks a crate/barrel or kills a creature still stops there. A **second hit** clears broken barrels and boxes completely; opened chests can likewise be destroyed by a hit. Clearing remains gives no additional loot. Closed chests remain protected and must first be opened with E / Use. Melee, projectiles, and offensive scrolls can clear remains; later shots pass the cleared spot. Boomerangs turn back on their first outbound impact rather than piercing, can leave the impact surface, and stop if their return path crosses a target. Stone stops projectiles. All fourteen weapon types appear in ordinary loot and merchant stock, with distinct held and ground silhouettes. Aim with the mouse on desktop or face/tap the target on touch; Attack uses the equipped weapon. Rarity and chapter improve power; the equipment panel displays total strike power, reach, and recovery.

All loose drops, including gold, potions, gear, ammo, and scrolls, disappear after **30 active seconds**. Incompatible armor, ammo, and scrolls dropped when changing weapons disappear after **10 active seconds**. Both blink during their final five seconds. Equipped and carried items do not expire; pause and shopping freeze ground-item timers. Saved runs preserve remaining time, and Delete/Undo preserves the item's remaining lifetime instead of granting a fresh timer.

## Living nests and unstable chambers

Each nest has its own adult parent spider, including nests outside the usual spider realm. If the knight leaves a triggered nest with living spiderlings, that nest's brood combines into its parent, forming a visibly larger giant with **3x the normal floor-scaled maximum vitality and base attack damage**. Its web strike inflicts that damage as well as rooting; ordinary webs remain root-only. Speed, web timing, and movement collision radius stay normal so the giant can traverse passages; the parent's current health fraction is preserved. If the parent was killed, surviving spiderlings form one new giant instead. No babies are duplicated, no kill rewards are awarded for absorbed babies, and repeated entry/exit never stacks the multiplier. Clearing every egg or killing all babies before leaving prevents the transformation. Leaving during the countdown does not cancel it: any later hatch outside the room combines immediately.

Entering a silken nest starts a **four-second** egg-hatching countdown, shown by amber rings and a warning. Each surviving egg sac hatches **three** small spiderlings with 10 vitality and a very fast 245-unit/second chase. Destroy sacs with melee or projectiles before they hatch to prevent their brood; intact eggs hatch only once, even after leaving and returning. Hatching removes the corresponding web patch. Spiderlings pursue the knight rather than other monsters, respect walls and merchant sanctuaries, and never award loot. Adult spiders strike after a **0.08-second** windup anywhere in their shown attack cone. The web has no projectile travel and roots for one second, including dodge displacement; a hit sends the spider rushing in for a melee attack. Walls, containers, leaving the cone, dodging/invulnerability, and merchant sanctuary can prevent the root. Timers freeze while paused.

On non-boss floors, each ordinary room has a seeded **4%** chance to be unstable. Entrance/merchant and stair rooms are excluded. Time advances only while the knight is inside the unstable room; after seven seconds, an amber square warns for two seconds before a tile opens into a dark, gold-edged pit. Later collapses are six seconds apart, with at most three holes per unstable room. Tiles stay away from stairs and intact furnishings. Entering or dodging across a pit descends **exactly one floor**, releases held controls, and uses the existing safe floor-arrival path. Floors 8 and 16 have no collapsing rooms/pits, and other multi-floor drops cannot skip the next boss gate.

The Node suite checks all eight ranged weapons with all seven special-ammo types, class-specific pickup and dropping, automatic regular fallback, and pause/cooldown guards.

## Enemy factions and crowned cycles

Ordinary enemies cannot damage or poison/burn other enemies. Enemy shots are still blocked by creatures and intact containers, but an allied creature takes no damage/status from the impact. Enemy projectiles expire at the radius of their displayed attack cone. Enemy melee, charge, lightning, web and boss attacks target the knight. Hidden traps and their swarms target the knight only; once disarmed, traps and their swarms target monsters only.

**Bosses guard Floors 8 and 16** in each 16-floor cycle; their forms rotate among dragons, necromancers, wizards, and empowered versions of other monsters on harder cycles. Every boss has melee and ranged attacks and summons up to four weaker, related minions. A living boss seals every route down; traps, collapse pits, and fissures cannot bypass it, and any multi-floor fall from below is capped at the next boss floor. Kill it to open the stairs and collect a reward cache: about **1,000 gold**, a powerful weapon and armor, three spells, and special ammunition. A brief tune and shower of gold-piece effects celebrate the victory without interrupting play; after Floor 16, the final stair starts a harder cycle with your gear and progress intact. Each additional cycle adds 25% of base enemy vitality/damage and +5 weapon power; speed/timing stay unchanged. Health refills on floor arrival as usual. A new run explicitly resets cycles/crowns.

Subtly mismatched floor tiles mark **crossfire traps**. Eight arrows—ordinary, fire, poison, or lightning—rush from both sides of the room toward the tile, dealing a one-time 50%-of-max-health hit to each eligible target. Disarm the trap first to make it target monsters instead. **Glowing pedestals** release a destructible boulder from a random side when their treasure is claimed. It rolls forward at 105 units/second and steers sideways toward the knight at up to 65 units/second; stone walls block it. Over 12 active seconds it grows to double size and its single hit rises from 75% to 90% of maximum health. Sidestep it or destroy its 100 health with melee or ranged attacks. Another pedestal cannot be claimed while a boulder is active. Boulder and trap state persist in saves.

Run `python 3d_dungeons\crown_checks.py` for desktop/phone friendly-fire, activated-trap, actual boss-kill, uninterrupted celebration, and next-cycle controls. It accepts a deployed `?test` URL. Fixtures isolate mechanics rather than claiming an unassisted full playthrough.

## Single-use scrolls

**Gear / Map** has an on/off auto-equip button and a button cycling **Ranged / Magic / Melee** preference. Eligible upgrades within 3.75 tiles and clear sight fly toward the knight before equipping, leaving the old item on the floor. Weapons must match the preference and improve strike power; ties favor faster recovery, then longer reach. Magic preference equips a first wand even when its strike power is lower, then compares wands as usual. Compatible armor upgrades by reduction. Gear preferences are saved with the run.

Dropped **gold and potions** move toward the knight within 3.75 tiles. Ammo does so only with a ranged weapon, and scrolls only with a wand; eligible gear flies toward the knight when auto-equipment is enabled. Healing potions drop less often.

Run `python 3d_dungeons\loot_tuning_checks.py` for desktop and phone browser checks of pickup boundaries, collection, item lifetimes, and pause/shop timer protection. It accepts a deployed `?test` URL.

Open the **Scrolls** panel, choose a spell, then **right-click the game canvas** to aim and cast while holding a wand. **T** and the shared touch cycle button cycle stocked scrolls with a wand or special ammo with a ranged weapon; Game settings can rebind this key and the potion key (Q). **R** casts the selected scroll. Switching to a ranged or melee weapon drops carried scrolls; switching to a wand or melee weapon drops ammunition.

Wands come in Fire, Fireball, Lightning, Poison, Web, and Light varieties and carry a bonus equal to their floor. Fire projects a burning cone; Fireball explodes without applying burn. Poison fires a damaging ball and maintains at most one wand cloud at a time. Web roots enemies for one to five seconds and deals crushing damage over time. Light illuminates a wall-bounded cone, blinds enemies, and burns over time. Lightning fires a visible bolt and chains visibly to nearby enemies starting at +5. Fire, Light, Poison, and Web damage destructible objects; Poison and Web also damage them over time. Higher bonuses improve effects and add damage to offensive scrolls. Wands require robes; boss-only hooded robes also protect the head. Settings and runs are saved locally, not synced across devices.

## Traps and torchlight

Each generated hidden glint has an 8% seeded chance to contain a **Hidden Hoard** weapon when safely inspected. Its floor-level weapon roll gains exactly +5 strike power; the gold reveal and normal selectable pickup invite inspection. A treasure reveal permanently consumes the trap without arming, damage, spawning creatures, or descent. Walking onto an uninspected glint still triggers the original trap and forfeits its hidden reward. Rewards cannot repeat; eighth-floor boss gates remain sealed.

Tiny gold floor glints shine for 0.9 seconds in each 3.6-second cycle, then disappear completely. Hidden traps only glint where combined radial torch illumination exceeds 20%; the knight's navigation halo never exposes them. The HUD does not disclose an invisible glint, although ongoing inspection keeps its progress feedback. Stop **beside** a torchlit trap (within 72 world units, but outside its 23-unit trigger radius) for two uninterrupted seconds to reveal and disarm it. A progress ring confirms inspection; moving or stepping away resets it. Hidden traps ignore monsters and trigger when the knight crosses them.

Disarmed traps reset automatically for monsters: the knight remains safe, and the next monster crossing triggers the trap. Fire burns, poison damages over time, quicksand slows, and trapdoors kill monsters without moving the player. Fire, poison, quicksand, and trapdoor zones remain active for five seconds; explosions are brief. Bug/bat traps release three short-lived creatures that target the trap's eligible faction, never their own brood. Trap-origin creatures never drop loot; ordinary monsters retain their rewards. Each trap triggers only once after disarming.

Trapdoors send you to a randomly selected valid destination two to four floors below, using the same entrance, healing, realm, merchant schedule, and boss rules as normal descent. Any multi-floor fall is capped at the next eighth-floor boss gate, so it cannot jump over a boss. Boss floors convert trapdoors into explosion traps and contain no pits or fissures. The final two floors have no trapdoors; entrance sanctuaries and final exit chambers have no traps.

About 30% of ordinary rooms begin fully dark and 40% partially lit; each floor guarantees at least one of each. Entrance and final chambers start lit. Each room has four reachable sconces: dark rooms start with none lit, partial rooms with one, and lit rooms with all four. **Strike a torch with any weapon to light or extinguish it; E / Use and selection never toggle it.** Torches cast circular pools with smooth radial falloff and blended overlaps. Radius scales with room area and torch count. Cached visibility polygons stop light at solid walls while permitting natural spill through doorways. Corridors retain their smoothly edged 42% ambient visibility. A small personal halo, visible unlit sconces, minimap, and HUD keep navigation usable without revealing hidden traps. Glints use the same falloff and wall occlusion as rendered light. Merchants, chests, equipment, stairs, and revealed traps retain their E interaction priority. Changes persist for the current floor; floors regenerate on descent.

Body armor, boots, gloves, and helmets have four independent equipment slots and visible worn/ground shapes. Leather, chainmail, and plate body armor sit on the torso and shoulders, below the head; helmets cover the head, gloves the hands, and boots the feet. Every chest contains armor of a random slot; monsters, barrels, and crates can also drop it. Press E to equip deliberately. Replacing a piece only swaps that slot and drops the previous piece. Percentages add across slots, with total incoming damage reduction capped at 40%, including spells and dragon flame. Armor does not affect dodge invulnerability. All slots persist between floors; new runs begin without armor. The equipment panel lists every slot and the combined reduction; pickup comparisons show the matching slot. Treasure chests have domed gold-trimmed lids and locks; they open intact and grant loot. Crates are square, plank-built and crossed with pale braces; they splinter when destroyed and remain distinct from the separate breakable barrels.

Every armor slot follows the equipped weapon: ranged weapons (including guns) allow leather or chain; melee weapons allow chain or plate; wands allow robes. Manual attempts to equip incompatible armor leave it on the ground, and auto-equip ignores it. Changing weapons drops incompatible pieces while retaining compatible ones; older saved runs reconcile incompatible gear onto the ground on resume. Like other loose gear, these pieces eventually expire.

## Merchants and inactivity threat

Merchants also buy carried healing potions for **8 gold each** and any of the four scroll types for **12 gold each**. Separate Sell cards show the carried count and sell exactly one per click/tap; empty inventory disables the button. Sales neither equip gear nor alter merchant purchase stock. Trade is available only in the open merchant shop, and potion resale remains below its purchase price.

Even floors before the cycle finale have a clearly marked merchant in the entrance chamber. Press E nearby to open a safe shop. Each visit stocks one weapon, body armor, boots, gloves, a helmet, and five healing potions; item prices are shown in gold, unaffordable purchases explain the shortfall, and stock is finite for that floor. Purchased weapons and armor appear beside the merchant for deliberate E-based equipping, so a purchase never silently replaces current gear. The merchant chamber is a sanctuary: enemies cannot enter, and the player cannot take damage there.

Stillness warnings now select reachable, unobstructed points 90-150 world units from the knight, rather than distant random rooms where undead could remain unseen and outside the AI activation range. One or two emerge depending on available space, with 1.35 seconds of visible emergence before they can move or attack; all four sconces in the knight's room go out when they arrive. Other rooms keep their lights, and their sconces can be relit normally. The merchant sanctuary suppresses and resets stillness threats so its safe-room promise remains intact. No warning is shown without a valid local emergence point.

## Sound

Web Audio synthesizes evolving chapter-specific music using four rotating melodic motifs, changing four-bar harmonies, bass layers, syncopated phrase pickups, and softer ambient wind/torch textures. Weapon-specific strikes (steel swish, heavy axe, mace thud, spear rush), distinct creature voices and hit timbres, damage, coins, opening chests, barrel/crate breaks, armor clinks, potion pickup, healing, dodging, venom, lightning, fire and dragon cues all have separate feedback. Effects vary pitch/filter timbre and noise offsets per event independently of gameplay randomness. No external sound files or network requests are used.

**Sound effects** and **Music** are independent on/off buttons with separate gain buses. Music includes the low drone and torch/wind ambience; Sound effects controls every gameplay cue. Both default to on; the shared Volume slider defaults to 55% and affects both. Audio unlocks/resumes on clicks or keys, subject to browser autoplay policy. The status message explains blocked or unsupported audio and provides a retry path. Music/ambience fades on pause or tab departure; event tails finish naturally. Settings last for the current page session.

`DungeonAudio.diagnostic()` reports context state, post-volume analyser RMS, separate music/effects bus RMS, event counts, both mute states, volume, and startup errors. `audio_checks.py` validates gesture startup, real nonzero audio samples, event output, mute silence, unmute, zero-volume silence, and browser suspension recovery in isolated Microsoft Edge. `equipment_checks.py` verifies actual equipped/ground silhouettes, E-driven armor loot/equip/swap, damage reduction, all four independent audio toggle combinations, weapon-specific profiles, and randomized pitch. It saves gameplay and silhouette screenshots and JSON evidence to `D:\OneDrive\Scripts\games\emberkeep`.
