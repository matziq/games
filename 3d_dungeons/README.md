# Emberkeep: The Ashen Crown

Open `index.html` directly in a desktop browser. It is a self-contained, offline HTML5 action RPG with embedded artwork and no installation, external requests, or dependencies.

## Mobile and Android

Phone and tablet layouts use the available viewport height and safe-area insets, with no horizontal page scrolling. Drag the MOVE pad to walk and face the knight; hold Attack with another finger to keep striking. Tap the hall to aim without moving. Use / Equip opens chests, equips gear, trades, or descends; Dodge and Heal use the same resolve and potion rules as the keyboard. Touch cancellation and tab departure release held input. Gear / Map opens a compact equipment/map drawer and pauses the game; close it and tap Resume journey to continue. Music, sound effects, volume, pause, and new-run controls remain available. Desktop keyboard/mouse controls are unchanged.

The local Android package is `D:\OneDrive\Scripts\games\emberkeep\Emberkeep-Android.apk`; the standalone export is `D:\OneDrive\Scripts\games\emberkeep\Emberkeep.html`. Android 8.0 or later and an up-to-date Android System WebView are required. Copy the APK to the phone, open it from Files, allow that app to install unknown apps if prompted, and install Emberkeep. Start the adventure with Enter the halls to unlock audio. No Internet permission is requested: the complete HTML and embedded art are packaged inside the APK, and the WebView blocks external requests and navigation. Backgrounding pauses gameplay/audio; Android Back asks before ending the unsaved run.

This is a locally debug-key-signed, installable sideload build, not a Play Store release. Keep `android-debug.keystore` in the private output folder to sign compatible future updates; do not commit it or the APK. A production/Play Store release requires a separately managed release signing key and store submission. There is no run persistence on Android, matching the browser game.

The tracked `android` directory contains a small native Java Activity, manifest, icon, and build script; it has no Gradle or third-party runtime dependencies. Install a JDK (21 used here), Android platform 36, and build-tools 36.0.0. Run `.\3d_dungeons\android\build.ps1` from the repository root, passing `-JavaHome` and `-SdkRoot` if needed. Defaults look for tools in the private output folder's `android-tools` directory. The script compiles Java with javac, converts it with D8, packages assets with AAPT2, aligns, signs, and verifies the APK; all build artifacts stay in the OneDrive output folder, not in the public Pages repository.

Run `python 3d_dungeons\mobile_checks.py` for phone portrait/landscape and tablet layout checks, simultaneous touch movement/attack, release, heal/dodge, gear, chests, stairs, merchant purchases, audio startup, and APK asset/DEX checks. Screenshots and JSON evidence go to `D:\OneDrive\Scripts\games\emberkeep`. An optional live `?test` URL repeats browser checks against deployment. Browser touch emulation does not substitute for native device testing.

## Play

WASD or arrow keys move. Mouse aims; hold left click on empty floor or Space to attack. Shift dodges in the movement direction (35 resolve; regenerates). Q drinks a potion (65 vitality). E opens nearby chests, equips dropped weapons or armor, and uses blue stairs. P or Escape pauses. New run confirms before replacing a live adventure. Leaving the tab pauses automatically.

Click or tap an item, torch, chest, safe trap, merchant, stairway, or furnishing **within reach** to select it without attacking or using it. A gold dashed outline and named selection panel identify the target. Repeated clicks/taps cycle all overlapping targets, including weapons and armor at exactly the same coordinates; the panel also lists separate buttons for each candidate. **E / Use** acts on the selected object. Clear, clicking empty ground, moving out of reach, or consuming the target clears selection; without selection, E retains its nearby-item behavior. **F / Torch** always lights/douses the nearest reachable torch, regardless of overlapping loot or selection. The touch Torch button is available alongside Attack, Use, Dodge, and Heal.

**X / Delete gear** removes only an explicitly selected loose weapon or armor, not equipped gear, treasure, or fixtures. The side selection panel's **Undo last delete** button restores that exact item once. Only the most recent deletion can be undone; another deletion replaces it. Undo does not change gold, equipment, monsters, or any other state. The latest deletion survives stairs, trapdoors, and fissures during the same run: on its original floor the item returns to its original location; after descent it returns safely at the knight's feet. A new run clears undo, and one-use restoration prevents duplication. All selection, Delete, Clear, and Undo buttons support touch.

Descend through ten numbered floors across five randomized realms, with two floors per realm. Each realm has its own floor and wall palette, architectural motifs, torch color, ambience, and creature roster: flooded limestone halls, a thornwood castle, a moonlit crypt, a ruined keep, and the Cinder Forge. Stairs change the atmosphere and enemies when entering a new realm and restore vitality on every descent. Cave spiders aim and spit venom that poisons; crypt wizards mark a location for lightning; cinder wizards launch fire that burns. Spell markers show where to dodge before impact. If you remain still for nine seconds, nearby floor markers warn that the dead are stirring; after twelve seconds zombies climb out beside you, extinguish every torch in your room, and attack. Moving resets the timer, but attacking does not. Gold and potions collect on approach. Successful strikes show green damage values over enemies; actual health lost shows red values over the knight, accounting for armor and invulnerability. Gold pickups show the collected amount, potions and equipped gear show their names, and opened chests and healing show clear event notices. Nearby notifications stack, fade, and stay within the playfield. Equipment pickups compare their stats with your current gear before equipping; replaced equipment remains on the floor. The final dragon appears only on floor 10 and alternates a telegraphed flame cone and radial fireballs. Kill it to recover the Ashen Crown. Experience increases rank and vitality. Runs are not saved between browser sessions.

The knight stays upright in every direction: left-facing art is a horizontal mirror, not a rotated body. Weapons and attack arcs still aim independently in any direction.

## Shifting halls and room identities

Every floor includes eight distinct ordinary room identities, layered over its existing realm palette: a graveyard with cross-marked headstones, provision stores with wooden cases and sacks, a winery with casks and bottles, a weapon armory with sword racks, an armor vault with armored stands and shields, a silken nest with eggs and webs, overgrown abandoned chambers with broken stone, and an ancient sanctuary with rune-carved columns. Their names appear below the realm heading. Furnishings do not block movement or change the connected floor grid, but stop projectiles until broken. Attack them (or select and Use to aim an attack) to destroy them for exactly **1-2 coins**, once, on every floor; no equipment or potion rewards come from decor. Breaking webbed eggs also removes their associated slowing web patch. Torches, stairs, and merchants are not destructible. Nest web patches slow the knight while crossing them. Existing monsters, loot, traps, and sconces remain functional.

Repeated bone glyphs, carpet stripes, colored floor-tile outlines, and other decorative tile marks have been removed for a cleaner stone floor. The supplied stone texture and masonry wall edges remain intact. Expired traps no longer show SPENT ovals. Active and SAFE traps, glints, inspection/countdown feedback, exit cues, and the actual earthquake cracks remain visible. Fissures retain their formation warning and gold-edged crack art without a repeated permanent floor label.

On floors 1-9, an occasional earthquake shakes the view and sounds a low rumble, then opens a gold-edged fissure after a three-second warning. The first can happen after 38-60 active seconds outside a merchant sanctuary; subsequent events are 45-70 active seconds apart, with at most three fissures per floor. Fissures have a brief opening grace period, remain visible on the floor, and drop you **exactly one floor** when walked or dodged across. They reuse the trapdoor descent path: input releases, vitality restores, and realm, merchant, and finale rules apply at the new entrance. A floor-9 fissure can lead to floor 10, never beyond it. The final floor has no earthquakes; falling never grants dragon victory. Pausing and shopping do not advance these timers.

## Equipment

Longswords, war axes, flanged maces, spears, and halberds have distinct silhouettes both in your hand and on the ground. Longswords recover in 0.36 seconds; axes deal more damage with slower recovery (0.46 seconds); maces trade reach for impact (0.42 seconds); spears offer longer reach (0.40 seconds); halberds have the longest melee reach and heavier strikes (0.57 seconds). These five use an aimed melee arc. Longbows fire fast arrows (0.65 seconds), throwing spears launch heavier javelins (0.72 seconds), throwing knives recover rapidly with lighter damage (0.30 seconds), throwing axes spin with heavier impact (0.66 seconds), and boomerangs return toward the knight (0.80 seconds; one in flight at a time). Ammunition replenishes automatically.

Player and enemy projectiles stop at the first living creature or intact container, including chests. A shot that destroys a crate/barrel or kills a creature still stops there; later shots can pass the cleared spot. Boomerangs turn back on their first outbound impact rather than piercing, can leave the impact surface, and stop if their return path crosses an intact target. Stone stops projectiles. All ten weapon types appear in ordinary loot and merchant stock, with distinct held, ground, projectile, and sound profiles. Aim with the mouse on desktop or face/tap the target on touch; Attack uses the equipped weapon. Rarity and chapter improve power; the equipment panel displays total strike power, reach, and recovery.

## Traps and torchlight

Tiny gold floor glints shine for 0.9 seconds in each 3.6-second cycle, then disappear completely. Hidden traps only glint where combined radial torch illumination exceeds 20%; the knight's navigation halo never exposes them. The HUD does not disclose an invisible glint, although ongoing inspection keeps its progress feedback. Stop **beside** a torchlit trap (within 72 world units, but outside its 23-unit trigger radius) for two uninterrupted seconds to reveal its identity and disarm it for safe walking. A progress ring confirms inspection; moving or stepping away resets it. Walking or dodging directly over a hidden trap triggers it once; monsters can trigger hidden traps too.

Revealed traps are marked SAFE and can be crossed without harm. Press **E** or tap **Use / Equip** beside a SAFE trap to deliberately activate it after a visible two-second countdown. Repeated Use does not restart the delay. Stand clear: active traps affect both the knight and monsters. Fire, poison, quicksand, and trapdoor zones remain active for five seconds to catch approaching enemies; explosions are brief bursts. Fire burns and poison damages over time, quicksand slows movement, and trapdoors remove ordinary monsters without moving the player. The final dragon cannot fall through a trapdoor. Bug/bat nests release three short-lived creatures with an emergence grace period; they attack the nearest eligible knight or monster, not just the player. Trap-origin creatures never drop gold, gear, or potions, however they die; ordinary monsters retain their normal rewards. Dodging protects against immediate damage, not the physical quicksand slowdown. Each trap can be activated only once.

Trapdoors send you to a randomly selected valid destination two to four floors below, using the same entrance, healing, realm, merchant schedule, and boss rules as normal descent. Near the end, the possible drop is bounded to floor 10 (floor 7: two or three; floor 8: two). Floors 9 and 10 have no trapdoors, so no drop lands beyond the finale or skips the dragon victory requirement. Entrance sanctuaries and final exit chambers have no traps.

About 30% of ordinary rooms begin fully dark and 40% partially lit; each floor guarantees at least one of each. Entrance and final chambers start lit. Each room has four reachable sconces: dark rooms start with none lit, partial rooms with one, and lit rooms with all four. Approach a torch and press **F / Torch**, or select it and press **E / Use**, to light or extinguish it. Torches cast circular pools with smooth radial falloff and naturally blended overlaps, not rectangular room cells or pixel-block darkness. Radius scales with the square root of room area divided by its torch count, keeping coverage roughly proportional without hard quarter-room boundaries. Cached visibility polygons stop torchlight at solid walls; light can spill naturally through open doorways. Corridors retain their 42% ambient visibility, smoothly fading into darker rooms instead of hard-edged rectangles. Darkness remains meaningful away from lit sconces; a small personal halo, visible unlit sconces, minimap, and HUD keep navigation usable without revealing hidden traps. Trap glints use the same radial falloff and wall occlusion as the rendered light. Without selection, merchants, chests, equipment, stairs, and revealed traps retain their previous E interaction priority; F bypasses that priority. Changes persist for the current floor; floors are regenerated on descent.

Body armor, boots, gloves, and helmets have four independent equipment slots and visible worn/ground shapes. Leather, chainmail, and plate body armor sit on the torso and shoulders, below the head; helmets cover the head, gloves the hands, and boots the feet. Every chest contains armor of a random slot; monsters, barrels, and crates can also drop it. Press E to equip deliberately. Replacing a piece only swaps that slot and drops the previous piece. Percentages add across slots, with total incoming damage reduction capped at 40%, including spells and dragon flame. Armor does not affect dodge invulnerability. All slots persist between floors; new runs begin without armor. The equipment panel lists every slot and the combined reduction; pickup comparisons show the matching slot. Treasure chests have domed gold-trimmed lids and locks; they open intact and grant loot. Crates are square, plank-built and crossed with pale braces; they splinter when destroyed and remain distinct from the separate breakable barrels.

## Merchants and inactivity threat

Floors 2, 4, 6, and 8 have a clearly marked merchant in the entrance chamber. Press E nearby to open a safe shop. Each visit stocks one weapon, body armor, boots, gloves, a helmet, and five healing potions; item prices are shown in gold, unaffordable purchases explain the shortfall, and stock is finite for that floor. Purchased weapons and armor appear beside the merchant for deliberate E-based equipping, so a purchase never silently replaces current gear. The merchant chamber is a sanctuary: enemies cannot enter, and the player cannot take damage there. Floor 10 is the final dragon floor and has no merchant.

Stillness warnings now select reachable, unobstructed points 90-150 world units from the knight, rather than distant random rooms where undead could remain unseen and outside the AI activation range. One or two emerge depending on available space, with 1.35 seconds of visible emergence before they can move or attack; all four sconces in the knight's room go out when they arrive. Other rooms keep their lights, and their sconces can be relit normally. The merchant sanctuary suppresses and resets stillness threats so its safe-room promise remains intact. No warning is shown without a valid local emergence point.

## Sound

Web Audio synthesizes evolving chapter-specific music using four rotating melodic motifs, changing four-bar harmonies, bass layers, syncopated phrase pickups, and softer ambient wind/torch textures. Weapon-specific strikes (steel swish, heavy axe, mace thud, spear rush), distinct creature voices and hit timbres, damage, coins, opening chests, barrel/crate breaks, armor clinks, potion pickup, healing, dodging, venom, lightning, fire and dragon cues all have separate feedback. Effects vary pitch/filter timbre and noise offsets per event independently of gameplay randomness. No external sound files or network requests are used.

**Sound effects** and **Music** are independent on/off buttons with separate gain buses. Music includes the low drone and torch/wind ambience; Sound effects controls every gameplay cue. Both default to on; the shared Volume slider defaults to 55% and affects both. Audio unlocks/resumes on clicks or keys, subject to browser autoplay policy. The status message explains blocked or unsupported audio and provides a retry path. Music/ambience fades on pause or tab departure; event tails finish naturally. Settings last for the current page session.

`DungeonAudio.diagnostic()` reports context state, post-volume analyser RMS, separate music/effects bus RMS, event counts, both mute states, volume, and startup errors. `audio_checks.py` validates gesture startup, real nonzero audio samples, event output, mute silence, unmute, zero-volume silence, and browser suspension recovery in isolated Microsoft Edge. `equipment_checks.py` verifies actual equipped/ground silhouettes, E-driven armor loot/equip/swap, damage reduction, all four independent audio toggle combinations, weapon-specific profiles, and randomized pitch. It saves gameplay and silhouette screenshots and JSON evidence to `D:\OneDrive\Scripts\games\emberkeep`. Pass a deployed URL ending in `?test` as its first argument to repeat the checks on the live game. Measurements validate generated browser audio, not human listening or physical speaker output.
