# Geodes

A single-file browser game.

## Run

- Open `geodes.html` in your browser.
- Or open the repo menu: `../gamemenu.html`.

## Notes

This folder contains a standalone HTML game. `geodes.html` is the browser build. `geodes.apk` is the portrait Android build.

On a phone, tap geodes to crack them, then tap the gem. Some climb and stay small. Others grow as they come toward the laser. A geode that reaches the gun ends the run. Every 10 cracked geodes extends a missile pod; the icons beside it are the ammo, and the pod retracts when it is empty. Pause and volume live in the top menu so they do not cover the gun.
