# Treasure of the Aztecs

This standalone canvas adventure is implemented in `treasure.html`. Explore connected rooms, collect treasure and useful items, avoid traps, and fight enemies while managing health and ammunition.

## Run

Open `treasure.html` in a browser, or launch it from the repository menu at `../gamemenu.html`. No build step is required.

## Controls

- **A / Left** and **D / Right**: move.
- **W / Up / Space**: jump or climb up.
- **S / Down**: climb down.
- **E**: use an action (including shooting or disarming when available).
- **F**: use the whip.
- On touch screens, use the on-screen movement, action, and whip buttons.
- Click the title screen or press **Enter / Space** to start. Use the speaker button to toggle sound.

The current game draws its visuals in canvas; it does not load the numbered JPEGs in the separate `Treasure of the Aztecs/images/` archive.
