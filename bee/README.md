# Beehive Construction

A standalone canvas simulation of worker bees gathering nectar from flowers and using it to expand a hexagonal hive. It has no win condition; watch the colony develop and adjust the environment while it runs.

## Run

- Open `bee.html` in a browser. No build step is required.
- Or launch it from the repository menu at `../gamemenu.html`.

## Controls

- **Resource density** changes how many flowers are available.
- **Simulation speed** ranges from 0.25× to 4×.
- **Show worker bee paths** toggles the flight trails.
- **Pause** stops the simulation; **Reset** starts a fresh colony.
- Press **M** to minimize/restore the controls or **H** to hide/show them.

The elapsed-time display excludes time spent paused.
