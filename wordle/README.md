# Wordle

This standalone browser game asks you to guess a five-letter word in six attempts. Each guess must be in the built-in valid-word list. Green tiles mark correct letters in the correct positions, yellow tiles mark letters elsewhere in the answer, and gray tiles mark letters not in the answer.

## Run

Open `wordle.html` in a browser, or launch it from the repository menu at `../gamemenu.html`. No build step is required.

## Controls and features

- Type with a physical keyboard or use the on-screen keyboard; **Enter** submits and **Backspace** removes a letter.
- Use the seed controls to share or replay the same puzzle.
- Open **Help** for the in-game rules and scoring.

Statistics, streaks, and high scores are stored in browser storage.
