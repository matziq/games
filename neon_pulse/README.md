# Neon Pulse

Neon Pulse is a dependency-free local audio player for desktop and Android. It plays MP3, WAV, and device-supported FLAC files with three audio-reactive Canvas visualizers.

## Run on PC

Open `index.html` in a modern browser, or serve the repository and visit `/neon_pulse/`.

## Controls

- Add or drag multiple audio files to create a playlist.
- Switch between Bars, Orbit, and Wave visualizers.
- Use Space to play/pause, Left/Right to seek, and M to mute.
- Use `neon_pulse.apk` for the packaged Android build when available.

Audio stays on the device. No file is uploaded.
