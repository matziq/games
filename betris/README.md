# Betris

Betris is a standalone browser version of a falling-block puzzle game. Place pieces to complete horizontal rows; completed rows clear, award points, and advance the level. Pieces come from a shuffled seven-piece bag.

## Run

Open `betris.html` in a browser, or launch it from the repository menu at `../gamemenu.html`. No build step is required.

## Controls

- **Left / Right**: move the piece.
- **Down**: soft drop.
- **Up / X**: rotate clockwise.
- **Z / Ctrl**: rotate counterclockwise.
- **Space**: hard drop.
- **P / Esc**: pause or resume.
- On touch screens, use the on-screen controls or swipe on the board.

The in-game **Help** panel shows the current keyboard controls. Settings and high scores are stored in browser storage.
