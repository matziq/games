# Treasure of the Aztecs image archive

This folder contains 33 numbered JPEG images (`images/treasure_of_the_aztecs_0001.jpg` through `0033.jpg`). They are an image archive, not a runnable game: the current browser game is `../treasure_aztecs/treasure.html` and generates its visuals in canvas rather than loading these files.

To play the game, open `../treasure_aztecs/treasure.html` in a browser or use the repository menu at `../gamemenu.html`.
